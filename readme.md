# TenderPulse

TenderPulse is a modern tender intelligence platform that helps businesses discover, analyse and track procurement opportunities.

## Features

- Fast tender search
- Country filters
- AI-ready architecture
- Secure authentication
- Premium analytics
- Email alerts
- PDF & Excel exports

## Technology

Frontend

- CSS
- JavaScript

Backend
